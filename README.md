# 평온의 방

현재 한국을 배경으로 한 1인칭 스토리 중심 추리·탈출 게임입니다.

회복 프로그램에 참가한 김수혁은 깊은 산속 연구소의 잠긴 방에서 깨어납니다. 탈출을 시도하던 중 정전으로 문이 열리고, 서로 다른 경로로 들어온 사람들과 마주칩니다. 서로를 경계하면서도 정보를 맞춰 외부 연락이 가능한 장소로 향하는 이야기입니다.

## 현재 상태

- 엔진: Ren'Py 8.5.3 / 1920x1080
- 대상: Windows PC
- 표현: 정지 삽화, 텍스트, 효과음 중심. 인물 음성 없음.
- **2026-09-27: 설계 문서 전환 완료.**
- 현재 실행되는 게임은 새 장면 1의 `방 조사 → 정전 → 열린 문`까지 구현합니다. 이후 집단 탈출 이야기와 새 인물은 아직 구현 전입니다.
- 구 장면 1의 일기·0611·배식·기억 삭제 반복 시스템은 새 장면 1에서 제거했습니다.

- [줄거리·세계관 기준](docs/줄거리-세계관-기준.md): 인물, 사건 순서, 시설·통신 규칙, 결말, 미정 사항.
- [구현 핵심 원칙](docs/구현-핵심-원칙.md): 표현·시점·기록·실패 원칙.
- [구 장면 1 명세](docs/장면1-구현명세.md): 과거 설계 참고 전용. 최신 코드와의 일치나 새 설계 유효성을 보장하지 않습니다.
- [작업 지침](AGENTS.md): 작업 범위와 새 설계 적용 기준.
- [기술 이슈](docs/known_issues.md): 기존에 기록한 이슈. 이번 문서 작업에서 재검증하지 않았습니다.

## 폴더

- `game/`: Ren'Py 소스와 게임 이미지·글꼴·음원
- `tools/`: 보조 스크립트
- `docs/`: 설계·구현 원칙·기술 이슈
- `test-results/`: 테스트 산출물

Ren'Py SDK, 세이브, 캐시, 컴파일 파일과 배포 빌드는 저장소에 포함하지 않습니다.

## 다른 PC에서 작업하기

1. GitHub Desktop에서 이 저장소를 Clone합니다.
2. 별도로 Ren'Py SDK 8.5.3을 준비합니다.
3. 작업을 시작하기 전에 Fetch origin과 Pull origin을 실행합니다.
4. 작업이 끝나면 사용자가 직접 변경 사항을 Commit하고 Push합니다.

두 PC에서 동시에 같은 파일을 수정하지 않습니다.
