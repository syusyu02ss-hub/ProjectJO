# 평온의 방

현재 한국을 배경으로 한 1인칭 스토리 중심 미궁 어드벤처입니다.

플레이어는 온결의 회복 프로그램에 참가한 김수혁의 시점에서 방을 조사하고, 수첩에 남긴 단서를 근거로 판단합니다. 잘못된 판단은 짧은 배드엔딩과 정온회의 기억 삭제 절차인 ‘정리’로 이어지며, 소지품에 남은 기록을 통해 체크포인트로 복귀합니다.

## 현재 상태

- 엔진: Ren’Py 8.5.x
- 대상: Windows PC
- 구현 범위: 제1장 「괜찮아지는 방」 제작 중
- 표현 방식: 정지 삽화, 텍스트, 효과음 중심
- 인물 음성: 사용하지 않음

## 폴더

- `game/`: Ren’Py 소스와 실제 게임에서 사용하는 이미지·글꼴·음원
- `docs/`: 기획서, 시나리오 작성 양식, 구현 원칙

Ren’Py SDK, 세이브, 캐시, 컴파일 파일과 배포 빌드는 저장소에 포함하지 않습니다.

## 다른 PC에서 작업하기

1. GitHub Desktop에서 이 저장소를 Clone합니다.
2. 별도로 Ren’Py SDK 8.5.x를 준비합니다.
3. 작업을 시작하기 전에 `Fetch origin`과 `Pull origin`을 실행합니다.
4. 작업이 끝나면 변경 사항을 Commit하고 Push합니다.

두 PC에서 동시에 같은 파일을 수정하지 않습니다.
