# 평온의 방 · Windows 데모 v0.2.1

탐색 중심의 심리 공포 어드벤처. 로비 도입, 방 탐색, 어두운 복도에서의 만남과 선택까지 플레이할 수 있습니다.

## 다운로드와 실행

릴리스의 Assets에서 `ProjectJO_Demo_v0.2.1_Windows.zip`을 받으세요. `Source code` ZIP은 실행용 데모가 아닙니다. 압축을 풀면 한글 게임 폴더와 `평온의 방.exe`가 나옵니다.

직접 다운로드: <https://github.com/syusyu02ss-hub/ProjectJO/releases/download/v0.2.1/ProjectJO_Demo_v0.2.1_Windows.zip>

ZIP 전체를 압축 해제한 뒤 `평온의 방.exe`를 실행하세요. Windows 64비트용이며 Ren'Py나 Python의 별도 설치는 필요하지 않습니다.

## 포함 사항

- 조사 위치 표시를 숨긴 배포용 탐색 화면과 확장된 클릭 영역.
- 7초 감소 바와 0.5초 유예가 있는 복도 선택, 시간 초과 실패 분기.
- 수정된 메뉴 명칭, 인물 배치, 방 배경 규격, 전용 앱 아이콘.
- 제작 출처 및 네 종류 글꼴의 라이선스 고지.
