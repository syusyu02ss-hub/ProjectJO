# Known issues

## 방 배경 해상도 — 적용 방식 변경

- 원본 `room_cold.png`(1672×941)는 보존한다.
- `tools/prepare_room_background.py`로 Lanczos 보간한 `room_cold_fhd.png`(1920×1080)를 정전 전후 배경에 적용했다.
- 기존 화면과 같은 전체 프레임 배율을 사용해 구도·사물 위치·클릭 영역을 유지한다. 자르기, 색보정, AI 재생성은 하지 않는다.
- 실행 시 저해상도 파일을 확대하는 대신 미리 보간한 파일을 사용한다. 원본에 없는 세부를 복원하는 초해상도 처리는 아니므로, 네이티브 고해상도 원화 수준의 선명도를 보장하지 않는다.
