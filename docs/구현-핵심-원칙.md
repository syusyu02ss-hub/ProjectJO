# 구현 핵심 원칙

## 몰입 방식

이 작품의 목적은 화면의 움직임을 생생하게 재현하는 것이 아니다. 정지된 삽화와 텍스트, 효과음을 바탕으로 플레이어가 장면을 머릿속에서 완성하게 한다.

- 움직임이 필요한 장면은 영상이나 세부 애니메이션 대신 전후 정지 화면으로 표현한다.
- 문, 카트, 인물과 사물의 움직임은 텍스트와 핵심 효과음만으로도 완전히 이해되어야 한다.
- 배경은 공간과 분위기를 전달하며, 작은 시각 요소를 찾아야만 단서를 이해하는 구조를 사용하지 않는다.
- 단서의 내용과 공간 관계는 반드시 지문과 수첩에도 기록한다.
- 긴장감은 문장 길이, 줄바꿈, 침묵, 소리의 발생과 소멸로 만든다.
- 화면 변화는 장면 전환, 암전, 제한적인 색조 변화로 사용한다.

## 시각 방향

- 마지막 야외 장면 전까지 어둡고 채도가 낮은 서늘한 색조를 유지한다.
- 배경은 세부 묘사보다 스산한 분위기와 읽기 쉬운 실루엣을 우선한다.
- 등장인물은 상반신만 표시한다. 전신이 필요한 구도에서는 인물을 화면에 표시하지 않는다.
- 인물의 외형은 승인된 기준 이미지를 고정해 사용한다.
- 윤서아의 제1장 표정은 기본, 옅은 미소, 다정한 미소 세 장을 사용한다.
- 김수혁은 1인칭 주인공이므로 제1장에서 화면에 직접 표시하지 않는다.
- 배식 직원은 화면에 표시하지 않고 텍스트와 효과음으로만 표현한다.

## 음향

- 모든 등장인물은 음성을 사용하지 않는다.
- 효과음과 환경음을 중심으로 구성한다.
- 배경음은 반드시 필요할 때만 사용하며, 없는 편이 좋으면 제외한다.

## 정보 원칙

- 플레이어가 아는 것과 주인공이 아는 것은 같다.
- 수첩 기록은 김수혁이 실제로 적는 장면이 있을 때만 추가된다.
- ‘정리’는 시간을 되돌리지 않고 최근 기억만 지운다. 소지품과 수첩 기록은 유지된다.
