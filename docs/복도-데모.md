# 복도 데모 · 2026-10-20

사용자가 승인한 포트폴리오 데모 범위. 장면 1의 종료 카드를 제거하고 문을 나서는 동작에서 암전과 복도 페이드로 이어진다.

- 수혁은 자기 이름과 참가 경위를 알고 있다. 기억상실 반전이 아니다.
- 감각에 매달리는 독백, 시간과 장소에 대한 불안, 서아에 대한 의심을 거쳐 다른 발소리를 듣는다. 수혁이 멈추자 상대도 멈추며 긴장이 커진다.
- 상대는 박도현이나 데모에서는 이름과 얼굴을 공개하지 않는다.
- 도망: 벽 모서리에 막혀 멈추고 상대와 경계하며 대화한다.
- 말 걸기: 상대의 경고와 반문을 거쳐 같은 질문에 도달한다.
- 정면 돌파: 도현이 머리를 가격하고 수혁이 쓰러지는 배드엔딩. 선택 직전 재시도는 게임 기능이며 기억이나 기록을 새로 만들지 않는다.
- 합류점에서 수혁은 이름과 온결 참가 경위 중 무엇부터 설명할지 고민한다. 상대의 “너, 누구야?”에 “내가… 누구냐고?”라고 반문하며 암전한다.
- 걸음을 멈춘 뒤 마지막 발소리와 빈 대사 한 번, 짧은 정적을 둔다. “내가 멈추니까.” / “상대도 멈췄다.”에서 낮은 불협화음을 재생한다. 복도 원고의 나머지 말줄임표는 제거했다.
- 공통 대사창 하단의 작은 삼각형은 글자가 모두 출력된 뒤에만 표시한다. 클릭·Enter·Space의 기존 진행 동작을 유지한다.
- 풀버전은 이후 차분히 참가 경위를 설명할 예정. 데모에는 그 답변을 넣지 않는다.
- 발소리는 유한 길이 효과음이며 상대와 수혁이 멈추는 지점에서 정지한다. 선택지에서만 초침을 재생하며 선택 즉시 끈다.
- 기존 메뉴 복도 배경을 어둡게 보정해 사용하며 새 인물 이미지나 음성을 추가하지 않는다.

검증: 통합 테스트에 정상 대화, 도주 합류, 돌파 실패 후 재시도 세 경로를 포함한다. 이번 실행 환경에서는 Ren'Py 실행 전 Windows DLL 재할당 오류가 발생하여 런타임 검증을 완료하지 못했다. 런처에서 린트와 테스트, 실제 음향 타이밍을 확인해야 한다.
