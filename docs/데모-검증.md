기록일: 2026-10-22. 대상: Windows 데모 v0.2.1.

## 확인된 결과

- 제작자와 외부 지인들이 Windows에서 배포본이 정상 실행된다고 보고했다. 정확한 OS 빌드·PC 수·사용한 ZIP 해시는 별도로 수집하지 않았다.
- v0.2.1 ZIP 무결성, 최신 소스·배경·아이콘 포함, 개발용 저장·캐시·테스트 제외를 파일 검사로 확인했다.
- 실행 파일에 삽입한 아이콘을 Windows에서 추출해 새 아이콘임을 확인했다.

## 2026-10-22 재패키징

제작 출처와 글꼴 라이선스를 보강해 ZIP을 다시 만들었다. ZIP CRC 검사 통과: 1,607개 파일, 70,750,080바이트. SHA-256: `27025d5044fddbac4ccaa63c7313508605df0ffa51f1fa8a075bc7f0eb29a8f2`.

이전 ZIP과 비교해 추가된 것은 나눔명조·기쁨밝음 라이선스 두 파일이며, 변경된 것은 `CREDITS.md`와 저장 경로 설명 주석을 추가한 `options.rpy`다. `options.rpy`의 실행 내용은 동일하다. 나머지 파일은 바이트 단위로 동일하다. 이 새 ZIP 자체를 재실행했다고 기록하지 않는다.

## 자동 실행 환경 상세

2026-10-22, 자동 실행 도구에서 Ren'Py 검사 명령과 동봉 Python 버전 확인 모두 Windows DLL 재할당 오류로 프로세스 시작에 실패했다. 게임 코드 실행 전 발생하며 원인 DLL은 확인되지 않았다. 사용자·지인의 정상 실행 보고와 별개다. `game/tests.rpy`의 시나리오 작성을 자동 테스트 통과로 기재하지 않는다.
